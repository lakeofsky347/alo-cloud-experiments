# ALO 云端实验计划

日期：2026-10-30。状态：研究主线已确定，正式执行合同未冻结。

本项目以 **M1 单题自身反馈**和 **M2 跨任务组织学习**为主线，先完成 M1 的独立准备与验收，再推进 M2；跨组共享后置。本仓库只提供实验计划与初步代码，不能据此启动正式采集。详细规则见[实验协议](protocol.md)，剩余工作见[实现状态](implementation_status.md)。

## 比较对象

## 题集与样本

SWE-bench Lite 用于仓库修复，ProgramBench 用于程序行为重建。两轨按各自原生评分分别报告，不合成跨基准总分。覆盖层为 SWE 评价侧参考 patch 新增与删除行数 ≤5、6–20、>20，以及 ProgramBench 固定上游 difficulty 的 easy、medium、hard；它们不是已经验证的任务跨度因果变量。

模型 API 身份、数据集、运行库和测试资产的固定版本目标见[模型与题集版本清单](models_and_benchmarks.md)。其中 ProgramBench 源码 commit 与 HF 测试资产 revision 是不同对象，须分别绑定。

| 阶段 | 每轨不同任务数 | 安排 |
| --- | ---: | --- |
| Strong 开发选型 | 3 | 每覆盖层 1 题，四候选同题，各一次 B0 |
| M1 正式比较 | 6 | 每覆盖层 2 题，每配置 B0 和自身反馈 B1，无重复采样 |
| M2 学习 | 4 | G2 persist／reset，两条事前固定顺序 |
| M2 独立 probe | 2 | 从终态统计副本或共同先验开始，禁止更新 |

两轨共 **30 个新任务身份，其中正式部分 24 个**。开发、M1、M2 学习和 probe 的任务身份互不重叠；选题前核查暴露史。仓库／程序家族重叠须记录，不能把任务身份未暴露等同于仓库外泛化。具体题单和评分版本仍待冻结，不能因模型表现、费用或未知结果事后换题。

已有[任务、暴露与历史存储行政记录](../study_records/README.md)可供定位：保留原始30题预选和有序候补，并列记录旧QC替换与原生平台停止状态。它们补齐资料索引，不将候选清单升级为已完成正式冻结。

## M1：同题自身反馈

每题各配置从相同公共任务初态和本系统共同组织先验出发。先完成各组独立 B0 并封存，再分别从本组完整检查点建立 B1，只用自身合法公开反馈续答。组别顺序按各轨任务位置轮换；该题 B1 沿用 B0 顺序。下一题重置组织经验。

主要终点为 B1 原生质量，主比较为 G2−G1 Strong、G2−G3，分轨分析。B0 质量、B0→B1 变化、费用、用量、时间及未知覆盖为辅助读数。B0→B1 包含追加计算与正常修改，不能单独证明组织更新的因果收益。

## M2：跨题统计迁移

主要对照为 G2 persist 与 reset。每条序列从共同先验开始，两臂使用相同顺序、任务初态、工具和逐题资源规则；按冻结规则交替执行两臂。每道题重建工作区、会话、角色身份和执行随机状态，persist 只迁移白名单统计，reset 每题恢复共同先验。

执行顺序为：**全部学习流 → G1／G3 固定参考 → 终态独立 probe → 关闭凭据后的独立终评**。固定参考对本轨四道学习题和两道 probe 各执行一次，不随两条顺序重复计数。每道 probe 独立使用对应 persist 终态的统计副本或共同先验；reset 不携带最后学习题的题内后验。probe 不更新统计、不回写、不用于调参。

M2 分轨报告 persist−reset、逐题质量与资源、终态 probe 和组织状态轨迹。两条顺序及其相邻任务相关，不能把序列位置当作独立序列。当前样本用于有限任务集估计，不能据此宣称总体架构优效或稳定学习优势。

## 资源与下一阶段

每模型累计上限 **50 CNY**，四模型合计 **200 CNY**，包含已经发生的使用和仍未解决的预留；新建仓库、平台或批次不重置额度，也不挪用模型间余额。本仓库不携带历史账本；真实调用前必须在独立私有运行存储中核对并绑定期初占用和预算可行性，缺失时停止派发。

计划上限为 Strong／M2 单元 32 请求、M1 B0 32 请求、B1 16 请求；各单元另设 900000 tokens、120 次工具、1200 秒墙钟、单命令 60 秒及每请求输出参数 4096。所有规划、选择、验证、失败和重派开销计入账本。这些上限不是完成全部任务的费用保证，完整计量与执行合同见[协议](protocol.md)。

付费日程、标价和样本见 [protocol_freeze.md](protocol_freeze.md) 与 [cost_projection.md](cost_projection.md)。Strong 已按业主决定固定，不再跑开发集选型。A1–A3 机制消融独立冻结；X1 共享实验后置，不作为全部主实验的共同前置。
